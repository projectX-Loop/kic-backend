# 커밋 작성

1. [공통 규칙](../../../AGENTS.md)의 커밋 형식을 확인한다. 현재 브랜치, git status, 작업 트리 diff와 staged diff를 살피고 새 파일은 내용을 직접 확인한다.
2. 요청 범위의 변경을 의도별로 묶고 각 묶음의 제목을 정한다. 계획이나 메시지 요청은 여기서 마친다.
3. 커밋 요청이면 한 묶음씩 파일 또는 hunk를 선택해 스테이징하고 staged diff를 검토한다. 기존에 스테이징된 다른 작업이 섞여 있으면 그 작업의 스테이징 상태를 보존하고 요청 범위만 분리할 수 있을 때 커밋한다.
4. 생성한 커밋의 해시·제목과 남은 변경을 보고한다. 로컬 커밋에서 작업을 마친다. 이 스킬은 절대로 푸시하지 않는다. 원격 푸시는 사용자가 직접 수행한다.
