# PR 작성

1. [공통 규칙](../../../AGENTS.md)의 PR 형식을 확인한다. 요청한 대상 브랜치 또는 저장소 기본 브랜치를 기준으로 커밋 목록과 병합 기준점 이후의 diff를 읽는다. 작업 트리에만 있는 변경은 PR 내용에서 제외한다.
2. 전체 변경의 목적을 제목으로 쓰고, 본문에는 리뷰어가 동작을 확인하는 데 필요한 변경 이유·내용과 실제 검사 결과를 담는다. 관련 이슈와 API 예시는 공통 규칙을 따른다.
3. 초안 요청이면 제목과 본문을 반환한다. 게시 요청이면 대상 및 소스 브랜치와 기존 PR을 확인해 중복 생성을 피한다. 사용자가 푸시한 원격 브랜치로 PR을 생성한다. 대상 커밋의 푸시가 필요하면 사용자에게 알리고 게시를 보류한다. 게시 후 PR 링크를 반환한다.
